物流发货助手 Browser Core 隐私政策

更新日期：2026年10月3日

一、产品说明

“物流发货助手 Browser Core”是“物流发货助手”桌面软件的配套 Microsoft Edge 浏览器扩展。

本扩展仅在用户授权并使用的拼多多、京东及京东物流相关业务页面中执行受控的浏览器自动化操作，包括元素定位、点击、文本输入、页面内容读取、元素状态判断、等待页面状态变化、复选框和原生下拉框操作、Frame / iframe 页面上下文识别、用户主动发起的文件上传及业务报表下载状态确认。

本扩展不用于广告、用户画像、跨网站跟踪或与物流发货业务无关的用途。

二、可能处理的数据

在用户主动使用物流发货助手相关功能时，本扩展可能访问或处理当前授权业务页面中的网站内容、订单与物流信息、文本字段、页面状态、元素属性，以及可能包含收件人姓名、联系方式、收货地址等个人身份相关信息的业务数据；也可能处理用户主动选择并上传至业务网站的文件内容。

本扩展不会主动读取与物流发货业务无关的浏览历史，不会主动读取用户保存的密码，也不会将 Cookie 用于广告、用户画像或跨站追踪。

三、数据用途

上述数据仅用于完成用户主动发起的物流发货及相关浏览器自动化操作，例如查询订单或物流状态、填写业务页面字段、执行用户请求的网页操作、上传用户指定的业务文件、确认报表下载或页面处理结果，并在物流发货助手桌面程序与浏览器页面之间传递必要的业务结果。

本扩展不会将用户数据用于广告、营销画像、信用评估或贷款用途。

四、本地通信

本扩展通过本机地址 127.0.0.1 与用户设备上的“物流发货助手”桌面程序通信，仅交换必要的结构化操作指令和业务结果。

本扩展不会因为该本地通信功能而向任意远程网站开放浏览器控制接口。

五、本地存储

本扩展可能使用 Microsoft Edge 扩展 storage 保存扩展实例标识、运行状态、连接和重连状态以及必要的本地诊断信息。

扩展 storage 不用于保存用户密码、支付信息或完整 Cookie。

六、下载权限

本扩展使用 downloads 权限，仅用于监测用户通过物流发货助手在拼多多、京东及京东物流业务页面发起的业务报表下载，并确认下载状态。

本扩展不会浏览、上传或分析与物流发货助手无关的其他个人下载文件。

七、网页导航和 Frame 权限

本扩展使用 webNavigation 权限识别授权业务页面中的 Frame / iframe 页面上下文，以确保自动化操作执行在正确的页面和 Frame 中。

该权限不用于建立用户浏览历史档案或跨网站跟踪用户。

八、远程代码

本扩展不会从远程服务器下载并执行 JavaScript 或 WebAssembly 代码。所有可执行代码均随 Microsoft Edge 扩展程序包提供。本扩展不使用 eval、new Function 或类似机制执行来自远程来源的任意代码。

九、数据共享和出售

除用户主动使用的业务功能所必需的处理外，我们不会出售用户数据，也不会将用户数据转移给第三方用于广告、营销、用户画像、信用评估或贷款用途。

本扩展处理的数据主要在用户自己的设备、物流发货助手桌面程序以及用户主动登录和使用的拼多多、京东、京东物流业务服务之间流转。

十、用户控制

用户可以随时停止使用本扩展，也可以通过 Microsoft Edge 的扩展管理页面禁用或卸载本扩展。

十一、数据安全

我们采用合理的技术措施限制扩展仅在声明的业务网站范围内运行，并限制扩展与本机物流发货助手之间的通信。扩展不会申请与其核心功能无关的网页权限。

十二、未成年人

本扩展面向物流及电商业务工作人员使用，并非专为儿童或未成年人设计。

十三、隐私政策更新

如果扩展的功能、权限或数据处理方式发生重大变化，本隐私政策会相应更新。
